# Допустимые значения в форме

Числовые поля имеют нижнюю и верхнюю границы, чтобы уменьшить число ошибок ввода.
Это **ограничения интерфейса**, а не нормы анализов или диагностические пороги.
Значение внутри границ не подтверждает применимость модели к конкретному пациенту.

| Показатель | Допустимый ввод |
| --- | ---: |
| Возраст, целые годы | 18–100 |
| Билирубин, мг/дл | 0,1–100 |
| Холестерин, мг/дл | 10–2 000 |
| Альбумин, г/дл | 0,2–10 |
| Медь в моче, мкг/сут | 1–1 000 |
| Щелочная фосфатаза, Ед/л | 1–20 000 |
| SGOT, исходная шкала данных (Ед/мл) | 1–1 000 |
| Триглицериды, мг/дл | 10–2 000 |
| Тромбоциты, исходная шкала данных | 1–2 000 |
| Протромбиновое время, с | 5–100 |

Категории выбираются из фиксированных списков, стадия — от 1 до 4.
Возраст примера округляется до целого года. Перед запросом к API число лет
переводится в дни: `int(round(возраст * 365.25))`.

## Основания для границ

Единого клинического минимума и максимума для каждого показателя нет:
референсные интервалы и измеряемый диапазон зависят от метода и лаборатории.
Например, [CDC: альбумин](https://wwwn.cdc.gov/nchs/data/nhanes/public/2021/labmethods/BIOPRO-L-MET-Albumin-508.pdf)
разделяет диапазон измерения 0,2–6,1 г/дл, расширяемый разведением,
и референсный интервал 3,5–5,2 г/дл. Ограничивать ввод только нормой нельзя:
отклонения от неё важны для этой задачи.

Границы таблицы выбраны для демонстрационного приложения с учётом лабораторной
документации и диапазонов `data/train.csv`. Это решения проекта, а не пределы,
утверждённые перечисленными источниками. Они допускают патологические значения
и все значения исходного CSV, но отсекают явные ошибки масштаба.

Источники для проверки единиц и выбора границ:

- [CDC: билирубин](https://wwwn.cdc.gov/nchs/data/nhanes/public/2019/labmethods/BIOPRO-K-MET-Total%20Bilirubin-508.pdf):
  измеряемые значения не ограничиваются нормой; верхняя граница формы ниже
  опубликованного предела отчётности 175,5 мг/дл.
- [CDC: липиды, раздел «Lipids in Serum or Plasma», пункт 9](https://wwwn.cdc.gov/nchs/data/nhanes3/manuals/labman.pdf):
  высокие значения холестерина и триглицеридов измеряют после разведения.
  Холестерин в CSV достигает 1 775 мг/дл, поэтому форма допускает до 2 000.
- [Mayo Clinic Laboratories: медь в суточной моче](https://mml.testcatalog.org/show/CUU):
  единицы — мкг/24 ч; взрослый референсный интервал не используется как предел ввода.
- [University of Iowa: протромбиновое время](https://www.healthcare.uiowa.edu/path_handbook/handbook/test1595.html):
  показатель задаётся в секундах, а не в INR; референсный интервал не ограничивает ввод.
- [Документация исходного PBC-набора](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/pbc.html):
  подтверждает единицы меди, билирубина, липидов, альбумина и ферментов.
  Для SGOT сохранена историческая шкала набора; современные значения АСТ в Ед/л
  нельзя подставлять без подтверждения сопоставимости методов.

Ограничения формы не меняют схему API или правила подготовки обучающего CSV.
Для подключения другой лаборатории нужны согласование единиц, пересмотр границ
и отдельная оценка качества модели.
